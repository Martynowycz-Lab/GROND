# Security

GROND processes local scientific files and can launch external crystallographic programs configured by the operator. Treat configuration files and endpoint command templates as executable input. Do not run an unfamiliar configuration against sensitive data until its paths and command templates have been reviewed.

To report a security problem, use a private GitHub security advisory for `Martynowycz-Lab/GROND` when that option is available. If private reporting is unavailable, contact the repository maintainers through the Martynowycz Lab GitHub organization before opening a public issue. Include the affected GROND version or commit, operating system, a minimal reproduction, and the practical impact. Do not attach private diffraction data, credentials, or proprietary program files.

Scientific disagreements, numerical accuracy questions, and ordinary crashes can use the public issue tracker when they do not expose private information. GROND is alpha research software; supported versions and current scientific limits are described in [LIMITATIONS.md](LIMITATIONS.md) and [CHANGELOG.md](CHANGELOG.md).
